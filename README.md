# Windows 11 setup

### Hardware
- [Anker SD Card Reader USB 3.0](https://link.amazon/B0imNaOhe)
- [Micro SDXC Lexar 64Gb taxa de escrita 48MB/s](https://link.amazon/B0bRLAYTs) 

### Pré instalação
- [Rufus Portável](https://rufus.ie/pt_BR/)
- [Windows ISO](https://www.microsoft.com/pt-br/software-download/windows11)
- Execute o Rufus e grave a iso no Micro SDXC
- Reinicie o computador e use a tecla para selecionar o dispositivo de boot (F8)

### Novo disco
- Caso a instalação seja realizada em um novo disco, desconecte o disco anterior para que seja instalado o **boot loader** nele.
- Se o disco anterior permanecer conectado, a inicialização será realizada pelo **boot loader** dele, criando uma dependência desnecessária.

### Windows setup
- Barra de tarefas → Microsoft Edge → Menu de contexto → Desafixar da barra de tarefas
- Barra de tarefas → Microsoft Store → Menu de contexto → Desafixar da barra de tarefas
- Configurações da Barra de tarefas → Itens da barra de tarefas → Pesquisar → Ocultar
- Configurações da Barra de tarefas → Itens da barra de tarefas → Visão de tarefas → Desativar
- Configurações da Barra de tarefas → Itens da barra de tarefas → Comportamentos da barra de tarefas → Ao usar várias telas, mostrar meus aplicativos da barra de tarefas em: → Barra de tarefas onde a janela é aberta 
- Configurações → Personalização → Cores → Escolher seu modo → Escuro
