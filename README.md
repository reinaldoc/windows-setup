# Windows 11 setup

### Hardware
- [Anker SD Card Reader USB 3.0](https://link.amazon/B0imNaOhe)
- [Micro SDXC Lexar 64Gb](https://link.amazon/B0aqGdoqK) 

### Pre-install
- Download [Rufus Portável](https://rufus.ie/pt_BR/)
- Download [Windows ISO](https://www.microsoft.com/pt-br/software-download/windows11)
- Execute o Rufus e grave a iso no Micro SDXC
